## 1. 문제 정보

문제명, 분야, 제공 파일, 실습 환경을 먼저 적습니다. 공개해도 되는 문제인지, 대회 규정상 풀이 공개가 허용되는지도 확인합니다.

## 2. 관찰한 사실

문제를 처음 확인했을 때의 정보와 가설을 구분합니다.

```bash
file ./challenge
sha256sum ./challenge
```

파일 형식과 해시값은 분석 대상이 무엇인지 명확하게 하기 위한 기본 정보입니다.

## 3. 접근 과정

검증한 가설을 시간순으로 정리하고, 실패한 접근에서도 얻은 정보를 남깁니다. 최종 결과만 설명하면 풀이를 이해하기 어렵습니다.

## 4. 결과와 회고

분석을 통해 알게 된 원리, 사용 도구, 놓쳤던 단서를 적습니다. 실제 문제를 풀었다면 문제 주최 측이 공개를 허용한 이후에 풀이를 게시하세요.

> 예시 템플릿입니다. 특정 CTF 문제의 실제 정답이나 개인 풀이 경험을 나타내지 않습니다.
