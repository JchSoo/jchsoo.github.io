## 문제를 재현할 수 있어야 한다

오류 메시지를 복사해 두는 것만으로는 나중에 같은 문제를 해결하기 어렵습니다. **환경, 입력, 기대한 결과, 실제 결과**가 함께 있어야 합니다.

| 항목 | 기록할 내용 |
| --- | --- |
| 환경 | 운영체제, 언어 및 런타임 버전 |
| 입력 | 에러를 재현할 수 있는 최소 입력 |
| 기대 결과 | 정상 동작 시 예상되는 결과 |
| 실제 결과 | 로그, 출력, 종료 코드 |

## 최소 재현 코드 만들기

원래 코드에서 문제와 관련 없는 부분을 제거해 작은 예제로 만듭니다.

```python
# 예시: 예상과 실제 결과를 함께 표시
expected = [1, 2, 3]
actual = sorted([3, 1, 2])
assert actual == expected
print("reproduced and verified")
```

## 해결 후에도 기록할 것

- 오류를 발생시킨 근본 원인
- 사용한 해결 방법과 선택 이유
- 동일한 문제가 재발하지 않도록 적용한 검증 방법

작성한 코드를 다시 읽었을 때 **왜 이 수정이 필요한지** 이해할 수 있도록 남기는 것이 목표입니다.
